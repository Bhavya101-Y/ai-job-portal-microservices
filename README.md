# Ai-job-portal-microservices
AI-powered Job Portal built with Microservices Architecture using Next.js, Node.js, Kafka, Redis, and PostgreSQL with Resume Analyzer, Career Guidance, and Razorpay Integration.

A scalable and production-ready Job Portal Web Application built using Microservices Architecture. This platform provides intelligent career tools like AI Resume Analyzer and AI Career Guidance, along with recruiter dashboards and secure payment integration.

🧠 Key Features


🔐 Authentication (Login / Signup / JWT)

👤 User Profile (Bio, Skills, Experience)

📄 AI Resume Analyzer

🤖 AI Career Guidance System

💼 Job Posting & Application System

🧑‍💼 Recruiter Dashboard

🔔 Real-time Notifications (Kafka + Email)

💳 Subscription System (Razorpay)

🔁 Forgot / Reset Password

⚡ Caching with Redis




🏗️ Microservices Architecture
The application is built using a microservices-based architecture, where each service runs independently and communicates via Apache Kafka.



Services:


-Auth Service

-User Service

-Job Service

-AI Service

-Notification Service

-Payment Service

-API Gateway
